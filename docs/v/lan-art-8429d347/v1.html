herdr-wecom-bot-bridge

企业微信 ↔ Herdr Bridge — CLI 使用说明 · v0.1.0

Usage

herdr-wecom-bot-bridge — 企业微信 ↔ Herdr Bridge：持有唯一企微 WebSocket，每条 Thread 配独立 Agent

Usage:
  herdr-wecom-bot-bridge <command> [options]
  herdr-wecom-bot-bridge <command> --help    查看子命令帮助

Commands:
  init            初始化配置和文件系统
  serve           启动常驻 Bridge daemon（持有唯一企微 WebSocket）
  status          查看 Bridge / Herdr / Thread 状态
  reconcile       修复已消失的 Herdr runtime 绑定
  sweep           休眠超时且无任务的 Thread
  herdr install   链接并启用随包发布的 Herdr plugin

Options:
  --home <dir>    状态目录（默认: ~/.herdr-wecom-bot-bridge）
  --verbose       输出调试日志
  --help, -h      显示本帮助

Config: ~/.herdr-wecom-bot-bridge/config.toml
凭据:   WECOM_BOT_ID / WECOM_BOT_SECRET（环境变量或 ~/.env）

首次使用流程

1. 安装: python3 -m pip install herdr-wecom-bot-bridge
2. 初始化: herdr-wecom-bot-bridge init
3. 凭据: 写 WECOM_BOT_ID / WECOM_BOT_SECRET 到环境变量或 ~/.env
4. 装 plugin: herdr-wecom-bot-bridge herdr install
5. 启动: herdr-wecom-bot-bridge serve
6. 运维: status / reconcile / sweep

企微侧命令

/new <主题> — 新建 Thread（每成员独立游标）
/threads — 列出 Thread（> 标记当前）
/use <ID> — 切换 Thread
/close [ID] — 归档 Thread
/status — 当前状态
架构: 企微单 WebSocket → Bridge daemon → Herdr Workspace/Tab → 每 Thread 独立 Agent（Pi RPC）· 30 分钟空闲休眠自动恢复
