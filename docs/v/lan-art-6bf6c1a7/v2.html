③ 怎么测这个 MCP（中文）

  1. 连通：curl http://192.168.26.166:3010/health（直连不通时经 7897 代理）
  2. 鉴权：无 token → 401；伪 wbmcp_ → 403；合法 token（DB ontology_mcp_projects 解析）→ 200
  3. 工具：标准 MCP Client（StreamableHTTPClientTransport + Bearer）initialize + listTools → 4 工具
