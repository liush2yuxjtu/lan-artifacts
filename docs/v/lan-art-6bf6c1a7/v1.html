winbrain_os 的 MCP（ontology-mcp-gateway）本地跑的前提

  • DATABASE_URL（Postgres 必填）+ ONTOLOGY_MCP_ENABLED=true；token 必须 wbmcp_[A-Za-z0-9_-]{40,64} 且经 DB resolve_ontology_mcp_project（SECURITY DEFINER）解析
  • Qwen provider（QWEN_KEY）— 无 key 时静默跳过；知识数据（wiki 页面）为空则问答无内容
  • 鉴权流程：/mcp/projects/<projectId> 端点 + Bearer token → DB 解析 → 每工具审计

④ 怎么测这个 MCP（中文答案）

  • 1. 连通性：curl -i http://127.0.0.1:3010/health → 200 ok；无 token POST → 401 ONTOLOGY_MCP_AUTH_REQUIRED
  • 2. 鉴权：伪造 wbmcp_xxx token → DB 解析失败 → 403；seed 一个合法 token 到 ontology_mcp_projects 表后再试 → 200
  • 3. 工具发现：标准 MCP Client（StreamableHTTPClientTransport）initialize + listTools → 预期 get_context_pack / read_page / concepts / lint_wiki / wiki_status / queries
  • 4. 数据问答：get_context_pack(goal) — 无 Qwen key 时返回空项目结构；有 key 需先跑 llm-wiki-compiler 编译知识
  • 5. 审计：每次工具调用写 ontology_mcp_audit_events（SUCCESS/FAILURE + durationMs + sourceAddress）
  • 6. 接入 DeepSeek 测试 pane：把 gateway 配进 --strict-mcp-config，在 herdr pane 里问业务问题看调用链
