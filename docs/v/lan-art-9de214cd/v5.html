Ontology Factory → MCP Schema 生成器

用 winbrain-data-ontology MCP 为所有未来 MCP 产出契约 schema · Claude Agent SDK 应用 · Hexagonal 架构 · 2026-08-07

〇、核心概念

  • winbrain-data-ontology 是 ontology factory 的输出（已发布语义目录：4 只读工具 + release 固定 + 脱敏）
  • 用它作为 schema 源：describe_contract / get_app_context 提取业务语义 → 生成未来 MCP 的契约 schema（工具/资源/输入输出 zod 规则）
  • 产出 schema.json + 脚手架 → 新 MCP 项目模板（new-sdk-app 风格）

② 数据流

ontology factory ──发布──▶ winbrain-data-ontology MCP（4 工具只读 · release 固定） │ describe_contract · get_app_context（按对话目标） ▼ MCP Schema 生成器（Claude Agent SDK 应用） │ ▼ schema.json（工具 / 资源 / 输入输出 zod 规则） │ ▼ scaffoldMcpProject ──▶ 未来 MCP 脚手架（new-sdk-app 风格）

③ Schema 生成规则（domain 纯函数）

  • 工具：从已发布 business/assets/mappings 派生 — 每资产生成 read 工具（如 get_ticket），只读注解 + release 参数
  • 资源：ontology://release/{releaseId}/items/{id} 模式的引用 URI 模板
  • 输入输出：字段 → zod schema（dataType 映射：varchar→string、int→number、boolean→boolean）
  • 契约元数据：contractVersion、promptMode=conversation、writePolicy=read_only（对齐现有 4 工具契约）
  • 边界：release 固定（混版本拒绝）、输出脱敏（sk-*/apiKey/token）、引用原文不伪造

④ Claude Agent SDK 应用结构（拟）

目录 · apps/mcp-schema-generator（新 SDK 应用）

  • src/index.ts — SDK 入口（query + 工具：describe / generate / validate / scaffold）
  • src/domain/mcp-schema.ts — zod 生成纯规则
  • src/application/use-cases.ts — generateMcpSchema / validateMcpSchema / scaffoldMcpProject
  • src/adapters/outbound/ontology-mcp-client.ts — 连 winbrain-data-ontology（HTTP 8319 · Bearer）
  • src/composition/create-runtime.ts — 装配（hexagonal 单一装配点）

复用

  • 仓库既有 DataOntologyCatalogPort 契约语义（4 工具不变）
  • SDK 应用自身只读、无宿主环境继承、fail closed（对齐 AGENTS.md 安全基线）
